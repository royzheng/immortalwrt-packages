# AIR6 user-space packages

This `air6` branch starts at `decf94639ffd6ddd26591c190b547c6b7eea150b` and maintains the owner's AIR6 user-space additions:

- `libs/mipc`, `net/mipc-wan`: modem IPC library and network utility.
- `net/air6-modem-chain-only`: modem services, SDK runtime material and supporting scripts.
- `net/air6-arp-monitor`, `net/air6-speed-monitor`, `utils/air6-event-logging`: monitoring applications.
- `net/air6-cpe-ui`: standalone CPE web application and backend.
- `net/mtwifi-cfg-air6`: the existing mtwifi configuration/bring-up integration.
- `utils/atcid`: retained SDK source reference, not a newly buildable OpenWrt package; see its README.

The monitoring packages obtain vendor libraries from `STAGING_DIR/usr/lib/air6-sdk`, populated by `air6-modem-chain-only`'s `Build/InstallDev`. They no longer link against the old `TOPDIR/package/vendor/...` path. Event logging explicitly depends on `mipc` for headers and the IPC library.

These packages were moved from the owner's source tree without claiming a new full firmware build. The modem-chain and mtwifi packages include existing prebuilt vendor components; migration does not convert these binaries into source-built software or change their original notices. The kernel/MT7990 implementation belongs to `royzheng/immortalwrt:air6`, and the LuCI modem app belongs to `royzheng/immortalwrt-luci:air6`.

Commit and push changes to this branch before updating feeds in the firmware build tree. A sibling submodule's unpushed working-tree changes are not used by a `src-git ...;air6` build.

## Runtime services

The modem package also owns the migrated vendor init services (storage, NVRAM, CCCI, AT/SMS, RIL, network, logging and power), scd configuration and mdlogger hotplug handler. Their existing daemon binaries are supplied by this package. The parent's personal `air6-license-init` service is excluded. Startup links are generated by the firmware build; no old rc.d snapshot is imported. Full device behavior remains untested after migration.
